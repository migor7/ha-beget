# Beget для Home Assistant

> 🤖 **Вайб-кодинг.** Интеграция целиком написана ИИ (Claude) по запросу в чате, код вручную не правился.
> Гарантий никаких: если что-то сломалось, открывайте issue с логом Home Assistant.

Кастомная интеграция: баланс и данные аккаунта хостинга [Beget](https://beget.com) в Home Assistant.
Данные запрашиваются через API Beget (`user/getAccountInfo`) **раз в сутки**. При ошибке повтор идёт через 30 минут, а кнопка «Обновить» запрашивает данные сразу.

## Сущности

| Сущность | Что показывает |
|---|---|
| Баланс | `user_balance`, ₽ |
| Дней до блокировки | `user_days_to_block` |
| Дата блокировки | сегодня + дней до блокировки |
| Списание в день | `user_rate_current`, ₽ |
| Тариф в месяц | `user_rate_month`, ₽ |
| Тариф в год | `user_rate_year`, ₽ (выключена по умолчанию) |
| Тариф | название тарифа; атрибуты: годовой ли тариф, сервер |
| Занято на диске / Заполнение диска | МБ и % от квоты (диагностика) |
| Сайты | число сайтов, атрибут `limit` (выключена по умолчанию) |
| Обновить (кнопка) | внеплановый запрос к API |

## Установка

1. Скопируйте папку `custom_components/beget` в `config/custom_components/` вашего Home Assistant
   (или в HACS: ⋮ → «Пользовательские репозитории» → `https://github.com/migor7/ha-beget`, тип «Integration»).
2. Перезапустите Home Assistant.
3. В панели Beget: **Настройки → Ограничения доступа** задайте отдельный пароль для API и в «Разрешённых методах» оставьте только «Управление аккаунтом» (по умолчанию API принимает пароль от аккаунта).
4. **Настройки → Устройства и службы → Добавить интеграцию → Beget**, введите логин и пароль API (или пароль аккаунта, если отдельный не задавали).

Если пароль API поменяется, Home Assistant сам предложит ввести новый.

## Пример автоматизации: предупреждение о низком балансе

```yaml
alias: Beget — скоро блокировка
triggers:
  - trigger: numeric_state
    entity_id: sensor.beget_LOGIN_dnei_do_blokirovki   # подставьте свой entity_id
    below: 7
actions:
  - action: notify.notify
    data:
      title: Beget
      message: >
        Баланс {{ states('sensor.beget_LOGIN_balans') }} ₽,
        до блокировки {{ trigger.to_state.state }} дн.
```

Иконка интеграции лежит в `custom_components/beget/brand/` (поддерживается с Home Assistant 2026.3; в более старых версиях иконка просто не отображается).
